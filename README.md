# 홋카이도 유빙 정보 웹앱 / Hokkaido Drift Ice Information Web App

홋카이도 오호츠크해의 유빙 정보를 제공하는 다국어 지원 웹 애플리케이션입니다.

A multilingual web application providing drift ice information for Hokkaido's Okhotsk Sea.

## 🌊 주요 기능 / Features

- **유빙 정보** / **Drift Ice Information**
  - 일별/주별 유빙 현황 보기
  - 주요 관측 지역별 유빙 상태
  - 7일 유빙 예보
  - Daily/Weekly drift ice status view
  - Ice conditions by major observation areas
  - 7-day drift ice forecast

- **관광 정보** / **Tourism Information**
  - 유빙 관련 관광 프로그램 (추가 예정)
  - 유빙 크루즈, 유빙 워킹 등
  - Drift ice-related tourism programs (coming soon)
  - Ice cruise, ice walking, etc.

- **맛집 정보** / **Restaurant Information**
  - 현지 맛집 및 특산물 정보 (추가 예정)
  - Local restaurants and specialties (coming soon)

- **다국어 지원** / **Multilingual Support**
  - 한국어 / Korean
  - English

## 📊 데이터 출처 / Data Sources

- [第一管区海上保安本部 海氷情報センター](https://www1.kaiho.mlit.go.jp/KAN1/1center.html)
  - 1st Regional Coast Guard Headquarters Sea Ice Information Center
- [日本気象庁 (JMA)](https://www.data.jma.go.jp/kaikyou/seaice/tile/jp/index_fct.html)
  - Japan Meteorological Agency

## 🚀 시작하기 / Getting Started

### 설치 / Installation

```bash
npm install
```

### 개발 서버 실행 / Run Development Server

```bash
npm run dev
```

브라우저에서 `http://localhost:5173`을 열어 확인하세요.

Open `http://localhost:5173` in your browser.

### 빌드 / Build

```bash
npm run build
```

### 미리보기 / Preview

```bash
npm run preview
```

## 🏔️ 유빙 시즌 / Drift Ice Season

- **시즌**: 1월 ~ 3월
- **최적 관람 시기**: 2월 중순 ~ 하순
- **주요 지역**: 아바시리, 몬베츠, 우토로, 라우스, 샤리

- **Season**: January ~ March
- **Best Viewing**: Mid to Late February
- **Main Areas**: Abashiri, Monbetsu, Utoro, Rausu, Shari
